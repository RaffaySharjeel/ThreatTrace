# ThreatTrace — Cyber Threat Intelligence Platform

ThreatTrace is a web-based Cyber Threat Intelligence and Security Incident Management platform designed to help organize and manage cybersecurity-related information in one centralized workspace.

The platform provides a structured interface for managing cyber threats, security incidents, investigations, digital assets, team members, and system activity.

Built as a **BSCS Database Management Systems (DBMS) project**, ThreatTrace focuses on practical database concepts through a real-world cybersecurity use case.

## Features

- **Dashboard:** Overview of security activities and threat statistics.
- **Threat Intelligence:** Manage and organize cyber threat information.
- **Incident Management:** Create, view, update, and delete security incidents.
- **Investigation Management:** Track and manage incident investigations.
- **Asset Management:** Maintain records of organizational assets.
- **Team Management:** Manage team members and their roles.
- **Audit Logs:** View system activity and record changes.
- **Settings:** Manage basic profile and application preferences.

## Project Architecture

ThreatTrace follows a modular web application structure:

- **Frontend:** Next.js application with reusable React components.
- **Backend:** Planned application logic and API integration.
- **Database:** Microsoft SQL Server relational database.
- **Data Management:** CRUD operations for the platform's main modules.

## Getting Started

### Prerequisites

Make sure you have installed:

- Node.js
- npm
- Git
- Visual Studio Code (recommended)

### Installation

1. Clone the repository:

```bash
git clone https://github.com/YOUR-USERNAME/ThreatTrace.git
```

2. Navigate to the project directory:

```bash
cd ThreatTrace
```

3. Install dependencies:

```bash
npm install
```

4. Start the development server:

```bash
npm run dev
```

5. Open your browser:

```text
http://localhost:3000
```
